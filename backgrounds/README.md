# 拍照背景

把圖片照下面的檔名放進這個資料夾（`backgrounds/`），推上 GitHub 後，拍照時的背景選單就會自動出現。沒放的檔名會自動略過。

| 檔名 | 在選單上的名字 | 人預設放在哪裡 |
|---|---|---|
| `keyart.jpg` | 主視覺 | 夏油傑下面的黃色空格（會裁切在格子框線內） |
| `team.jpg` | 全員 | 畫面下方正中間 |
| `school.jpg` | 咒術高專 | 畫面下方正中間 |
| `bg4.jpg` ～ `bg8.jpg` | 背景 4 ～ 背景 8 | 畫面下方正中間 |

注意事項：

- 副檔名必須是小寫的 `.jpg`。如果手上的圖是 `.png` 或 `.jpeg`，請先轉成 `.jpg`，或直接把檔名改成 `.jpg`（瀏覽器會依內容辨識格式）。
- 檔名大小寫要完全一樣（GitHub Pages 會分大小寫）。
- 建議長邊 1500～2500 像素；太大會讓網頁載入變慢。
- `keyart.jpg` 的格子位置是依那張 1419×752 的主視覺量的。換成別張圖的話，人一樣可以用手指拖曳、兩指縮放自己擺。

在 GitHub 網頁上傳的方法：打開這個資料夾 → 右上角「Add file」→「Upload files」→ 拖進圖片 → 「Commit changes」。上傳到哪個分支，就要確認 GitHub Pages 是從那個分支部署的。
